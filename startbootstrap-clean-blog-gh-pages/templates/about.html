About Me

This is what I do.

Hey, I'm Miguel — a developer in progress, literally.

I started coding from scratch, and instead of waiting to "feel ready" before showing anything, I decided to build while I learn. Every project on this site is real: code that runs, bots that automate tedious tasks, apps that solve an actual problem (even a small one, like not forgetting a birthday or not having to track expenses by hand every month).

Right now I'm deep in Python, C++, and databases — building the kind of fundamentals that don't show up in a README but definitely show up when the code doesn't break on the first try. "Make it work first, refactor later" is basically my work motto.

If you're looking for someone who ships working things and keeps getting better, get in touch — I'd love to hear what you're building.
